# Recursos visuales

Esta carpeta contiene las imágenes de la interfaz. Puedes reemplazarlas manteniendo el mismo nombre y formato (SVG recomendado), sin tocar el código.

| Archivo | Dónde se usa |
|---------|--------------|
| `logo.svg` | Sidebar, barra móvil e inicio de sesión |
| `favicon.svg` | Pestaña del navegador |
| `empty-projects.svg` | Estado vacío de proyectos |
| `empty-docs.svg` | Estado vacío de documentación |
| `empty-deliverables.svg` | Estado vacío de entregables |
| `empty-files.svg` | Estado vacío de recursos |

Recomendaciones:

- Mantén proporciones similares para no romper el layout.
- Usa la paleta morada (`#6d28d9`, `#8b5cf6`, `#ddd6fe`, `#f5f3ff`) para coherencia.
- Si cambias a PNG/JPG, actualiza la referencia en `web/templates` o mantén el nombre `.svg` con el nuevo contenido.
